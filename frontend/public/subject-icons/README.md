# Subject icons (optional)

Module cards use Flaticon icons via CDN by default. To use local files instead (e.g. for offline use or custom icons), add PNG files here with these names:

- `biology.png`
- `chemistry.png`
- `math-aa.png` (Mathematics – Analysis & Approaches)
- `math-ai.png` (Mathematics – Applications & Interpretation)
- `economics.png`
- `business.png`
- `physics.png`
- `psychology.png`
- `global-politics.png`

If a file is missing, the app falls back to the Flaticon CDN, then to subject initials.
